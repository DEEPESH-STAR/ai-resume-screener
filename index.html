    Fictional data. No signup. No uploads to a server.

    Decision support, not a decision maker. Coverage measures explicit skill mentions, not ability or suitability. AI similarity is uncalibrated and may be wrong. Missing evidence is not proof of missing skill. Verify with a consistent, human-led process; never automatically reject candidates.
    Built by Deepesh Pandey · MatchlineNo tracking. No database. Your review stays in this tab.

    Evidence before assumptions.

    Matchline helps a human reviewer locate job-related evidence. It does not rank candidates or recommend hiring decisions.

    • Quick review: exact skill and alias matching. This mode is rules-based, not AI. Negation and context require human checking.
    • Local AI: downloads an open-source sentence-embedding model from Hugging Face and runtime from jsDelivr. It suggests semantically related resume passages, not verified qualifications.
    • Privacy: this app does not send resume text to a server or save it to local storage. Model/runtime downloads expose ordinary connection metadata to their hosts. The browser may cache the model.
    • Fair review: use job-related skills only. Do not evaluate protected traits, names, photos, age, or background proxies. Label resumes anonymously and remove personal information before use.

    PDF and DOCX import downloads pinned reader libraries from jsDelivr. Password-protected, malformed and scanned files may not work. Text paste is always available.

    AI that runs on your device.

    Download the quantized all-MiniLM-L6-v2 model and Transformers.js runtime (tens of MB). First load can take a few minutes and use significant memory. A modern desktop browser works best.

    Only model and runtime files are fetched from Hugging Face and jsDelivr; this app does not transmit resumes. Results are suggestions requiring human verification. You can use quick review without AI.

    Clear this workspace?

    This removes the role, resumes, evidence and review flags from this tab. Export first if you want to keep a report. Model files cached by your browser are not removed.
